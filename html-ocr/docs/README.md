# Guide HTML OCR

Motore secondario manuale, indipendente dall'app Docker. Tutti i comandi delle
guide si eseguono da `html-ocr`, salvo diversa indicazione. I percorsi che iniziano
con `html-ocr/` o `projects/` nelle descrizioni sono relativi al repository.

| Guida | Contenuto |
| --- | --- |
| [Avvio e comandi](avvio-comandi.md) | Installazione, PowerShell, npm, offline e dry-run. |
| [Struttura dei dati](struttura-dati.md) | Foto esterne, JSONL append-only, cache e separazione dei progetti. |
| [OCR e convalida](ocr-validazione.md) | Letture concordi, timestamp, duplicati e verifica dell'archivio. |
| [Calibrazione e stime](calibrazione-stime.md) | Fatturazione dichiarata, crediti extra, token e limiti delle stime. |
| [Fonti e report](fonti-report.md) | Fonti con provenienza, Markdown, CSV e dashboard statica. |
| [Verifiche e problemi](verifiche-problemi.md) | Diagnosi, messaggi, codici di uscita e prove offline. |
| [Migrazione e privacy](migrazione-privacy.md) | Nuovi percorsi, integrità, backup ed esclusioni Git. |
| [Sviluppo e riferimenti](sviluppo-riferimenti.md) | Revisione, regole per modifiche e documento originale. |

Per iniziare: [README del motore](../README.md). Il
[demo inventato](../projects/demo/README.md) mostra i risultati senza dati reali.
Per l'altro flusso consultare le [guide dell'app principale](../../web-app/docs/README.md).
